# Lightbox - Cloud Storage Platform 📁☁️

**Lightbox** — це відмовостійка, контейнеризована хмарна платформа для збереження та керування корпоративними даними, розроблена як проєкт Приватного Підприємства (MVP). Система реалізує мікросервісну архітектуру, гнучке керування квотами користувачів, структурування файлової системи та безпечний стримінг медіа-вмісту.

## 🚀 Головні технічні переваги та фічі
* **Повна контейнеризація (Docker Compose):** Розгортання всього інфраструктурного стека (App, DB, Cache, Proxy) однією командою.
* **Висока відмовостійкість (Fault Tolerance):** Реалізовано архітектурний Fallback-механізм. У разі аварійної відмови Redis, додаток автоматично перемикається на роботу з MySQL. Обмеження `connectTimeout` до 1.5 с запобігає зависанню інтерфейсу для користувача.
* **Оптимізація навантаження:** Кешування профілів, сесій та важких запитів (наприклад, останніх завантажень) у RAM за допомогою Redis, що мінімізує прямі запити до диска.
* **Безпека та рольова модель:** Чітке розмежування прав доступу (Адміністратор підприємства / Співробітник) на рівні API-мідлварів. Захист від витоку структури БД при критичних помилках (HTTP 500).
* **Сучасний UX:** Плавний SPA-інтерфейс з динамічним рендерингом DOM, інтегрованими вікнами SweetAlert2 та іконками Boxicons.

## 🛠 Технологічний стек
* **Backend:** Node.js, Express, Multer (робота з файловими потоками)
* **Frontend:** Vanilla JS (SPA), HTML5, CSS3 (Flat UI), SweetAlert2, Boxicons
* **Database:** MySQL (Реляційна база, типи даних TINYINT(1) для Boolean-оптимізації)
* **Cache/NoSQL:** Redis (керування сесіями, кеш запитів)
* **DevOps/Infrastructure:** Docker, Docker Compose, Nginx (Reverse Proxy, роздача статики, SSL)

## 📦 Схема інфраструктури (Контейнери)
1. `nginx` — Вхідна точка (порт 80/443), проксіює запити, миттєво віддає статику фронтенду.
2. `app` — Server Node.js (Express), що містить усю бізнес-логіку системи.
3. `db` — СУБД MySQL з підмонтованим Docker Volume для персистентного збереження даних.
4. `redis` — Швидке сховище в оперативній пам'яті для сесій та кешу.

### Крок 1. Клонування репозиторію
```bash
git clone [https://github.com/NMihailo/js_lightbox.git](https://github.com/NMihailo/js_lightbox.git)
cd js_lightbox

### Крок 2. Запуск інфраструктури в Docker
```env
NODE_ENV=production
REDIS_URL=redis://redis:6379
DB_HOST=db
DB_USER=root
DB_NAME=lightbox
```
### Крок 3. Запуск інфраструктури в Docker
Запустіть збірку та оркестрацію мікросервісів у **фоновому режимі**:
```bash
docker compose up --build -d

### Крок 4. Доступ до платформи
